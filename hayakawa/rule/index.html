2. 研究会だけのルール

6半荘・ウマはワンツー

  • 1回の会で6半荘打ちます。6半荘の合計ポイントで順位を決めます。
  • ウマはワンツーです。1位+20・2位+10・3位−10・4位−20です。
  • オカ（+20）は1位がもらいます。順位点は11章の表です。

親の連荘は東場・南場ともあり

  • 親のアガリ・親の聴牌流局とも連荘し、本場を積みます。
  • 南4局で親がトップなら、アガリやめができます。

途中流局なし（Mリーグと同じ）

九種九牌・四風連打・四家立直・四開槓でも、局を最後まで続けます。3人が同時にロンした時は頭ハネです（6章）。

チョンボは満貫払い

Mリーグの −20ポイントの代わりに、チョンボした人が満貫分の点棒を払います。

チョンボした人払い方合計
子親に4,000点、子2人に2,000点ずつ8,000点
親子3人に4,000点ずつ12,000点
  • その局はやり直します。本場は増えません。

点数の報告

  • 半荘が終わったら、点数報告ページ に4人の席と点棒を入れます。
  • マイナスの点棒も、そのまま入れてください。
  • チョンボの満貫払いは、点棒でその場で払います。払った後の点棒を入れます。
  • ポイントは自動で計算されます。計算のしかたは「11. 順位点とポイント」です。

3. 1局の流れ

親と局の進み方

  • 半荘は東場と南場の2周です。
  • 親は起家から順に、右隣（下家）へ移ります。
  • 1局は、アガリ・流局・チョンボのどれかで終わります。
  • 洗牌（牌をかき混ぜること）はしません。局が終わったら、すぐ牌を卓の中へ流します。

流局と聴牌

  • 最後の牌までアガリがなければ流局です。途中で流局することはありません。
  • 聴牌の宣言は、東家・南家・西家・北家の順です。手牌を開けて見せます。
  • 役がなくても、形が聴牌なら聴牌と認めます（形式聴牌）。
  • 聴牌していても「ノーテン」と言って伏せてかまいません。
  • 自分の手牌と鳴いた牌だけでアガリ牌を4枚使っている待ちは、聴牌と認めません。

ノーテン罰符は、場に3,000点です。

聴牌の人数払う・もらう
1人ノーテン3人が1,000点ずつ払い、聴牌者が3,000点もらう
2人ノーテン2人が1,500点ずつ払い、聴牌者が1,500点ずつもらう
3人ノーテン1人が3,000点払い、聴牌者が1,000点ずつもらう
0人・4人やり取りなし

連荘と本場

  • 親がアガるか、親が聴牌で流局すると連荘です。
  • 親がノーテンで流局すると、親は下家へ移ります。本場は1本積みます。
  • 本場1本につき、アガリ点に300点を足します。ツモなら1人100点ずつです。
  • 子がアガると、本場は0本に戻ります。
  • 本場は卓の表示だけで数えます。百点棒は出しません。

海底と河底

  • 海底牌（最後にツモる牌）を引いた人は、カンもリーチもできません。
  • 海底牌を引いてアガらなければ、1枚捨てます。これが河底牌です。
  • 河底牌は、チー・ポン・カンできません。ロンはできます。

4. リーチ

  • 門前（鳴いていない）なら、リーチをかけられます。
  • 「リーチ」と言って、捨て牌を横に向け、千点棒を1本出します。
  • リーチの宣言牌でロンされなければ、リーチ成立です。
  • フリテンでもリーチできます。ツモ番が残っていなくてもリーチできます。
  • 宣言牌がチー・ポン・カンされたら、次の捨て牌を横に向けます。
  • リーチ後にアガリ牌を見逃してもかまいません。その後はフリテンになり、ツモでしかアガれません。
  • リーチ後の暗槓は、手の形（面子の組み合わせ）が変わらない時だけできます。

取り消しとリーチ棒

  • 「リーチ」と言っても、牌を捨てる前なら取り消せます。ただし、その局はアガリ放棄です。
  • 牌を捨てた後は取り消せません。
  • リーチ棒は、その後にアガった人が取ります。
  • 最後の局が流局で終わったら、場のリーチ棒はトップが取ります。
  • 聴牌していないリーチ（ノーテンリーチ）はチョンボです。

5. 鳴き（チー・ポン・カン）

どれが優先か

同時に声がかかったら、ロン → ポン・カン → チー の順に優先します。

  • 通らなかった鳴きは、罰則になりません。

チー

  • 上家（左隣）の捨て牌だけチーできます。
  • 取った牌を横に向け、手から出した2枚の左に置きます。

ポン

  • 誰の捨て牌でもポンできます。
  • 取った牌を横に向けて置きます。向きで、誰から取ったかを示します。
取った相手ポン大明槓
上家（左）左端を横に左端を横に
対面（向かい）真ん中を横に左から2番目を横に
下家（右）右端を横に右端を横に

食い替えは禁止

鳴いた直後に、鳴いた形と同じ面子を作れる牌を捨てることです。するとアガリ放棄になります。

例: 4・5 で 3 をチーして、6 を捨てる（3-4-5 と 4-5-6 の両方になる）→ 食い替え
例: 5・5 で 5 をポンして、5 を捨てる → 食い替え

カン

種類やり方
暗槓（アンカン）ツモの後、手の中の4枚を見せる。両端（または内側2枚）を伏せて右に出す
加槓（カカン）ツモの後、ポンした3枚に4枚目を重ねる
大明槓（ダイミンカン）人の捨て牌で、手の中の3枚と合わせて4枚にする
  • カンをしたら、王牌の最後から嶺上牌を1枚ツモります。
  • 槓ドラは、カンした時点ですぐにめくります（暗槓も明槓も同じ）。
  • 1局のカンは、全員合わせて4回までです。
  • 加槓の牌でロンされたら（搶槓）、そのカンはなかったことになり、槓ドラもめくりません。
  • 暗槓の牌では、どんな手でも搶槓できません（国士無双でも不可）。

鳴いた牌の置き場所

鳴いた牌は自分の右側に置きます。複数あれば、手前から奥へ鳴いた順に並べます。暗槓も同じ場所です。

6. アガリとフリテン

アガリの形

  • 4面子＋1雀頭、七対子、国士無双の3つです。
  • 役が1つ以上ないとアガれません（一翻縛り）。
  • ツモなら「ツモ」、ロンなら「ロン」と言って手牌を開けます。
  • ツモの時は、まずアガリ牌を見せてから手牌を開けます。
  • 嶺上牌でのアガリは、すべてツモアガリです。
  • アガリの確認が終わるまで、手牌・捨て牌・山を崩さないでください。

頭ハネ（ダブロンなし）

1つの牌に2人以上がロンしたら、1人だけがアガれます。放銃者から見て 下家 → 対面 → 上家 の順に優先です。

フリテン

フリテンの時は、ツモでしかアガれません。

種類どんな時いつ解ける
捨て牌自分の捨て牌にアガリ牌がある待ちが変わるまで
同巡内アガリ牌が出たのにロンしなかった自分がツモって捨てた時
リーチ後リーチ後にアガリ牌を見逃したその局の終わりまで解けない

役の重なり

  • 一緒に成り立つ役は、すべて重ねて数えます。
  • 嶺上開花と海底摸月は重なりません。

7. ドラ

種類決め方
表ドラドラ表示牌の次の牌。字牌は 東→南→西→北→東、白→發→中→白 の順
槓ドラカンのたびに、表示牌を1枚ずつ増やす
裏ドラリーチした人のアガリだけ。表示牌の下の牌で見る。槓ドラの下も見る
赤ドラ赤い5萬・5筒・5索が1枚ずつ
  • ドラは1枚につき1翻です。
  • ドラは役ではありません。ドラだけではアガれません。

  • 渡し間違いは、その半荘の中なら直します。半荘が終わった後は直しません。
例（1本場の子のツモ）: 「1,300・2,600 は 1,400・2,700」

11. 順位点とポイント

  • 半荘が終わった時の持ち点で順位を決めます。
  • ポイント＝（持ち点−30,000）÷1,000＋順位点 です。
  • 順位点は、ウマ（ワンツー）にオカ（+20を1位へ）を足した値です。
  • 1,000点が1ポイントです。100点は0.1ポイントで、丸めません。
順位順位点
1位+40
2位+10
3位−10
4位−20
例: 41,600点の1位 → +11.6＋40 ＝ +51.6
例: 35,800点の2位 → +5.8＋10 ＝ +15.8
1卓の例: 40,000／33,500／28,100／−1,600
→ +50.0／+13.5／−11.9／−51.6（4人の合計は0）

点数報告ページに4人の点棒を入れると、自動で計算されます。

同点のとき

  • 半荘の最後が同点なら、順位点を分けます（1位と2位が同点なら +25 ずつ）。
  • 割り切れない分は、起家に近い人が多く取ります。
  • 流局で終わった時に場のリーチ棒があれば、同点の人で均等に分けます。
  • 3人で1,000点を分ける時は、400・300・300 です。起家に近い人が400です。

6半荘の合計ポイントは 点数報告ページ に出ます。

12. 包（パオ）

役満を確定させる牌を鳴かせた人が、責任を負う決まりです。

役満パオになる時
大三元（ダイサンゲン）三元牌を2種類鳴いている（暗槓含む）人に、3種類目をポン・大明槓させた
大四喜（ダイスーシー）風牌を3種類鳴いている（暗槓含む）人に、4種類目をポン・大明槓させた
四槓子（スーカンツ）カンが3つある人に、4つ目を大明槓させた
  • その人がツモったら、鳴かせた人が全部払います。
  • 別の人がロンされたら、鳴かせた人と放銃した人が半分ずつ払います。
  • 本場の分は、鳴かせた人が払います。
  • ダブル役満以上の時は、パオの役満1つ分と本場を鳴かせた人が払い、残りはふつうに払います。

13. 反則と罰則

アガリ放棄

その局の終わりまでアガれず、チー・ポン・カン・リーチもできなくなります。牌はツモって捨て続けます。

反則どんな時
多牌・少牌手牌が多い・少ない（カンなしで14枚以上・12枚以下）
先ヅモ上家が捨てる前にツモった
食い替え5章
空鳴き「チー」「ポン」「カン」と言って鳴かなかった
リーチの取り消し「リーチ」と言って、捨てる前にやめた
手を見せないアガリ宣言「ツモ」「ロン」と言っただけで手牌を開けない
鳴きの言い間違い「ポン」「チー」「カン」を言い間違えた
誤った鳴き面子にならないのにチー・ポン・カンした（鳴きはなかったことにする）

「ツモ」と「ロン」の言い間違いは、注意のうえ言い直してかまいません。

アガリ放棄なのにチー・ポン・カン・リーチをしたら、チョンボです。

チョンボ（研究会 満貫払い）

  • アガれない手でアガリを宣言し、手牌を開けた。
  • ノーテンリーチ。リーチ後に手の形が変わる暗槓をした。
  • アガリの後、点棒のやり取りが済む前に山を崩し、手や裏ドラが分からなくなった。
  • 山や手牌をわざと崩して見せた。
  • 山を壊すなどして、続けられなくした。
  • チョンボした人は、満貫分の点棒を払います（2章の表）。
  • その局はやり直します。本場は増えません。
  • チョンボの局に正しいアガリがあれば、罰はありません。

Mリーグでは、チョンボは −20ポイントです。研究会は満貫払いに変えています。

くり返すと罰則になる行為

Mリーグでは、次の行為にイエローカードが出ます。くり返さないでください。

  • 声を出さずに鳴いた。動作が先で、声が明らかに遅れた。
  • わざとでなくても、牌を2枚以上見せた（山・手牌とも）。
  • 関係ない場面での強打・長考をくり返した。
  • ツモに時間をかける動作（牌を絞る・振りかぶる）をくり返した。
  • ツモった牌を手牌に入れる動作（小手返しなど）をくり返した。
  • ツモが早く、ポン・カンの時にツモ牌を見てしまうことをくり返した。
  • ため息やぼやきなど、相手を惑わす言動をくり返した。

14. 打ち方の決まり

  • チー・ポン・カン・リーチ・ロン・ツモは、必ず声に出してから動きます。
  • ツモは、上家が牌を捨て終わってから取ります。山に触ったら、もう鳴けません。
  • ツモって捨てるまでは片手で行います。牌を握ったままツモらないでください。
  • ツモった牌を、手牌の中に混ぜてはいけません。
  • 捨て牌は左から右へ、6枚ずつ並べます。7枚目から下の段へ。
  • 一度河についた牌は、取り戻せません。
  • 捨て牌にむやみに触らないでください。
  • ツモや打牌は、速すぎず遅すぎないペースで行います。
  • 強打は禁止ではありませんが、くり返すと罰則の対象になります。
  • 最初に自分の山を井桁に組みます。山を崩すと罰則の対象になることがあります。
