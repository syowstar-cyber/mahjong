# 早川麻雀研究会 点数 API の配置手順（Google Apps Script）

Halu杯の受け口（halu-cup リポの `gas/Code.gs`）とは**別のプロジェクト**として作る。データを混ぜないため。
ブラウザで人が行う（Claude は代行しない）。所要 5 分。ドライブの権限は求められない。

受け口を作るまでは、点数ページは各端末のブラウザにだけ保存する（ほかの人と共有されない）。

## 1. スクリプトを作る

1. https://script.google.com を開き、「新しいプロジェクト」。
2. `コード.gs` の中身を全部消し、この階層の `Code.gs` を貼り付けて保存（Ctrl+S）。
3. プロジェクト名を「hayakawa-mahjong」など分かる名前にする。

## 2. ウェブアプリとして公開する

1. 右上「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」。
2. 「次のユーザーとして実行」= **自分**、「アクセスできるユーザー」= **全員**。
3. 「デプロイ」→ 権限の確認が出たら自分のアカウントで許可する。
4. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピーする。

## 3. ページに URL を入れる

`hayakawa/score/config.js` の `window.HAYAKAWA_API = ""` の引用符の中に URL を貼り、commit → push。

## 使い方

- 1半荘ぶん（4人の席と点棒）を1回で送る。記録済みの半荘は上書きできない（受け口が `exists` で断る）。
- 直すときは、ページで4桁の番号を入れて「この半荘の点数を取り消す」→ 入れ直す。番号の照合はページ側だけ。
- 次の会を始める前は、エディタで関数 `resetAll` を選んで「実行」（全消去）。
- 保存先はスクリプト プロパティの `ROUNDS`（半荘 → 席と点棒）と `LOG`（送信履歴・直近100件）。
- 参加者を変えるときは、`Code.gs` と `score/index.html` の `PLAYERS` を同時に直す。`Code.gs` は「デプロイを管理」→ 新バージョンで反映（URL は変わらない）。
