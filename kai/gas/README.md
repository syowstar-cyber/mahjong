# 普段の回の受け口の配置手順（Google Apps Script）

第20回の受け口（halu-cup リポの `gas/Code.gs`）とは**別のプロジェクト**として作る。データを混ぜないため。
ブラウザで人が行う（Claude は代行しない）。所要5分。ドライブの権限は求められない。

**一度デプロイすれば、回が替わってもデプロイし直さない**（URL は変わらない。回ごとの置き場は `kai` で分かれる）。

## 1. スクリプトを作る

1. https://script.google.com を開き、「新しいプロジェクト」。
2. `コード.gs` の中身を全部消し、この階層の `Code.gs` を貼り付けて保存（Ctrl+S）。
3. プロジェクト名を「halu-kai」など分かる名前にする。

## 2. ウェブアプリとして公開する

1. 右上「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」。
2. 「次のユーザーとして実行」＝**自分**、「アクセスできるユーザー」＝**全員**。
3. 「デプロイ」→ 権限の確認が出たら自分のアカウントで許可する。
4. 表示された**ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピーする。
5. URL を Claude に渡す。Claude が各会の `kai/g/<会>/taikai.json` の `api` に入れ、テスト送信をして消す（受け口は1つをどの会でも使う。2026-10-25 にデプロイ済み）。

## 回ごとの作業（Claude が行う）

- 前日: その会の `taikai.json` の `kai` を新しい回の名前（`<会>-YYYY-MM-DD`）に替え、名簿を `tools/meibo.py` で受け口へ送る。手順は `docs/普段の回_手順書.md`（リポ直下の docs）。
- 終わった後: 名前を出しておく期間が過ぎたら、同じ送り方で名前を `''` にして消す。
- 日本語を含むテスト送信は、Git Bash の `curl -d` だと文字コードが崩れる。scratchpad の python（urllib・UTF-8）で送る（第20回の学び）。

## エディタで動かす関数（人が行う）

| 関数 | すること |
|---|---|
| `listKai` | 置いてある回の一覧（卓の数・名簿の人数・最終更新）と、保存領域の使用量を「実行ログ」に出す |
| `purgeKai` | 1つの回を消す。先頭近くの `const PURGE = '';` に回の名前を入れて保存し、実行する。終わったら `''` に戻す |
| `resetAll` | 全部（すべての回と送信履歴）を消す |

- 保存領域は全体で500KBまで。1回あたり数KBなので、目安で50回以上は置ける。`listKai` で量を見て、古い回から `purgeKai` で消す。
- `Code.gs` を直したときは「デプロイを管理」→ 編集（鉛筆）→ バージョン「新しいバージョン」→ デプロイ。URL は変わらない。
