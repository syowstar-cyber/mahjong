# 普段の回のキット（3麻・4麻・会ごと）

普段の回は、参加者ページ（`kai/`。日時と場所・組み合わせ・当日の流れ）と点数ページ（`kai/score/`）の2枚だけを使う。
Halu杯の記念大会（店の貸し切り・ゲストあり）の部品は halu-cup リポ（第20回の一式）にある。

## 会

| 会 | `?g=` | 設定の置き場 | 参加者ページのURL |
|---|---|---|---|
| Halu杯 | なし（`halu`） | `g/halu/` | https://syowstar-cyber.github.io/mahjong/kai/ |
| 早川麻雀研究会 | `hayakawa` | `g/hayakawa/` | https://syowstar-cyber.github.io/mahjong/kai/?g=hayakawa |

- 会を増やすときは `g/<会>/` に `taikai.json` と `kumiawase.json` を置く（会の名前は英小文字・数字・`-` で20字まで）。ページは同じものを使い、URL の `?g=<会>` で選ぶ。
- 受け口は1つ（`gas/`）をどの会でも使う。回の名前（`kai`）を `<会>-YYYY-MM-DD` にして、会と回が混ざらないようにする。
- 道具は `--group <会>` で会を選ぶ（既定は `halu`）。

## ホーム画面のアプリ（PWA）

- 会ごとに `g/<会>/manifest.json` とアイコン（`icon-512.png`・`icon-192.png`・`icon-180.png`）を持つ。`python kai/tools/make_pwa.py` が `taikai.json` の `short`・`group`・`color`・`pai` から作る（`short`・`color`・`pai` を変えたら作り直す）。
- ページは `?g=` から会の manifest を選ぶ。ホーム画面から開くと、その会の参加者ページが開く。
- 読み込みの手伝い（`sw.js`）は、ページの見た目（HTML・アイコン・manifest）だけを手元に置く。設定・組み合わせ（`.json`）と受け口は手元に置かず、いつも新しく読む。`sw.js` の中身を変えたら `CACHE` の番号を上げる。
- LINE で配るときは、URL に `openExternalBrowser=1` を付ける（LINE の中のブラウザでなく、Safari や Chrome で開く＝ホーム画面に追加できる）。貼る文は `docs/LINE案内文.md`（リポ直下の docs）。

## 回ごとに

- 書き換えるのは、その会の `taikai.json`（大会設定）と `kumiawase.json`（組み合わせ。`tools/kumiawase.py` が書く）の2つだけ。ページは触らない。
- ページは2つのファイルを毎回読み直す（キャッシュしない）。push してから1〜2分で全員の画面に出る。
- 名前はファイルに置かない。受け口の名簿（回ごと）にだけ持ち、ページが読んで出す。番号は回ごとに P1 から振る。
- 受け口の作り方は `gas/README.md`。前日・当日・終わった後の手順は `docs/普段の回_手順書.md`（リポ直下の docs）。
- 道具: 組み合わせを作る `tools/kumiawase.py`・名簿を送る／受け口を試す `tools/meibo.py`・結果を保管庫に残す形で出す `tools/kekka.py`。

| `players` | 出席者の数。P1〜P(この数) | `13` |
| `prelim` | 予選の半荘数 | `4` |
| `final` | 決勝。`tables`＝卓数（0＝決勝なし）、`hanchan`＝半荘数、`junni`＝1 なら順位決定戦あり（決勝に出ない人が、決勝1半荘目の時間に1半荘。書かなければなし） | `{"tables":1,"hanchan":2,"junni":1}` |

| `tables` | 卓番号の呼び名（空なら1から） | `[1,2,3]` |
| `locked` | 確定した半荘。送信も取り消しもできなくなる | `["1","2"]` |

| `tensu` | 点数表のページ（会のフォルダの中の .html）。書いた会だけ「点数表」のボタンが出る | `"tensu.html"` |

順位点の書き方:

- 固定（4麻の初期値。第20回と同じ）: `"uma": [30, 10, -10, -30]`。25,000持ち・30,000返しなら、オカ20を足して1位は+50。
- 返し以上の人数で変わる（3麻の決めごと）: `"uma": {"0": [30,-10,-20], "1": [30,-10,-20], "2": [20,0,-20]}`。返しちょうども「以上」に数える。表にない人数は `"1"` を使う。

計算のきまり:

- ポイント＝（点棒−返し）÷1,000＋順位点。1位にはオカ（返し−持ち点）×人数÷1,000を足す。丸めない（100点＝0.1ポイント）。
- 同点の順位点は分ける。0.1で割り切れない分は起家に近い方が多く取る。
- 予選の順位は合計ポイント。抜け番の半荘は0ポイント。
- 決勝に出るのは予選の上位（卓数×人数）。予選の最後の半荘で「お休み」（途中で抜けた）の人は飛ばして、下の人を繰り上げる。2卓以上は予選の順位で蛇行に分ける（2卓なら 1・4・5・8位／2・3・6・7位）。決勝を何半荘打っても卓の顔ぶれは同じ。
- 決勝に出た人を上に並べ、その下に予選の順で並べる。決勝が1半荘なら素点、複数なら決勝のポイント合計で比べる。卓をまたいで一緒に比べる。
- 決勝の同点は予選の順位が上の方を上にする。1半荘の同じ卓の中は起家に近い方を上にする。
- 予選の合計の同点は、同じ順位の数字で「同点」と出す。`nenrei` の会は、同点の人全員の生年月日が入ると年上から並べる（「年齢」と出す。同じ日なら同点のまま）。生年月日は受け口だけに置き、返すのは年上からの順（agerank）だけ。
- 順位決定戦（`final.junni` が 1）: 決勝に出ない人を予選の順に、上から mode 人ずつの卓に分ける。余りは下の卓から1人ずつ足す（3麻だけ。4人で3人麻雀を回す。7人なら3人卓と4人卓）。足しきれない余りは抜け番。点数は決勝1半荘目（`F1`）の、決勝の卓の後ろの番号の卓に入れる。ポイントはつけず、卓ごとに素点の多い順で最終順位を決める（卓をまたいで入れ替わらない。同じ素点は予選の順位が上の方）。最終順位は、決勝 → 順位決定戦の卓の順 → 残りの人（予選の順）。

## 組み合わせの作り方（tools/kumiawase.py）

```
python kai/tools/kumiawase.py                          … 作って成績を出すだけ（書かない）
python kai/tools/kumiawase.py --write                  … 前日: kumiawase.json に書く
python kai/tools/kumiawase.py --from 3 --absent P5 --write   … 当日: 3半荘目から組み直す（P5 が抜けた）
python kai/tools/kumiawase.py --check                  … いまの kumiawase.json を検査して成績を出す
```

- どれも Halu杯（`g/halu/`）を読み書きする。早川研は `--group hayakawa` を足す。

- 作るときに目指すこと: 同じ相手とできるだけ当たらない・抜け番は多く打った人から回す・一人ひとりの風を均等にする・同じ卓に続けて座らない。
- 同じ引数なら何度作っても同じ表になる。別の表にしたいときは `--seed 2` などを足す。
- 組み直し（`--from N`）は、1〜N−1半荘目をそのまま残し、そこまでの当たり方・風・抜け番を引き継いで N 半荘目から作る。
  - 抜けた人は `--absent` に書く。その人はそれ以降の半荘で「お休み」になる（0ポイント）。
  - 増えた人は、先に `taikai.json` の `players` を増やす。増えた人は打った数が少ないので、抜け番にはなりにくい。
- 成績の見方: 「余分に当たった回数」が「下限」と同じなら、それ以上は減らせない。人数と半荘数によっては、下限が0でも少し残る（例: 4麻13人4半荘は12組。探す回数を増やしても減らなかった）。
- 1回あたり2〜4秒。push してから1〜2分で、参加者ページと点数ページに出る。

## kumiawase.json（組み合わせ）

```json
{
  "kai": "halu-2026-11-14",
  "made": "2026-11-13 21:00",
  "from": 1,
  "rounds": {
    "1": { "tables": [ { "no": 1, "p": ["P3", "P7", "P1"] } ], "rest": ["P13"] },
    "3": { "tables": [ … ], "rest": [], "out": ["P5"] }
  }
}
```

- `rounds` のキーは予選の半荘の番号。`p` は席の順（東・南・西・北。東が起家。`bakime` が `true` の会では、同じ卓の顔ぶれだけ）、`rest` はその半荘の抜け番、`out` は途中で抜けた人。
- `made` は作った時刻、`from` はどの半荘から作ったか。2以上なら、参加者ページに「N半荘目から組み直しました」と出る。
- `kai` が `taikai.json` と違うときは、ページはこのファイルを使わない（前の回の表の取り違えを防ぐ）。
- 決勝と順位決定戦の卓は載せない。どちらも予選の順位から決まり、席は自動卓のサイコロで決める（`bakime` が `true` の会は牌を引いて決める）。
