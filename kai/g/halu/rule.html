2. 3人麻雀の決まり

牌と席

  • 2萬〜8萬は使いません。萬子は1萬と9萬だけです。
  • 筒子・索子・字牌は、4人麻雀と同じです。
  • 席は東家・南家・西家の3人です。北家はいません。
  • 東場・南場とも3局ずつです（東1〜東3局・南1〜南3局）。
  • ドラ表示牌が1萬ならドラは9萬、9萬ならドラは1萬です。

チーはなし

  • チーはできません。ポンとカンはできます。
  • 鳴いた牌は、取った相手が座っている方向（左・向かい・右）に向けて置きます（6章）。

北はふつうの字牌（抜きドラなし）

  • Halu杯 北は抜きドラにしません。ほかの字牌と同じように使います。
  • 北は役牌になりません（場風は東か南、自風は東・南・西です）。
  • ドラ表示牌が西のときは、北がドラです。

ツモ損なし（北家の分を折半）

  • Halu杯 ツモアガリでも、ロンより少なくなりません。
  • 4人麻雀なら北家が払う分を、残りの2人が半分ずつ足して払います。100点未満は切り上げます。
  • 1人が払う点は、点数表のページにあります。ロンの点数は、4人麻雀と同じです。
  • 本場の分だけは折半しません（ロン300点、ツモは1人100点）。
例: 子の満貫ツモ → 親が5,000点・子が3,000点（合計8,000点）
例: 親の満貫ツモ → 子2人が6,000点ずつ（合計12,000点）

ノーテン罰符（場に3,000点）

聴牌の人数払う・もらう
1人ノーテン2人が1,500点ずつ払い、聴牌者が3,000点もらう
2人ノーテン1人が3,000点払い、聴牌者が1,500点ずつもらう
0人・3人やり取りなし

3人麻雀でできない役

  • 三色同順はできません（萬子の順子が作れないため）。
  • 一気通貫・清一色・九蓮宝灯は、筒子か索子だけです。
  • 三色同刻は、1か9の刻子だけです。
  • 断么九は、筒子・索子の2〜8だけで作ります。
  • 国士無双・小四喜・大四喜には北が要ります。

ダブロンあり

  • Halu杯 1つの捨て牌に2人がロンしたら、2人ともアガれます。
  • 放銃した人が、2人にそれぞれの点数を払います。
  • 本場と場のリーチ棒は、放銃した人の下家（次の番の人）がもらいます。
  • アガった2人の中に親がいれば、親の連荘です。
例: 子の捨て牌に、親（12,000点）と子（3,900点）がロン → 放銃した子が合わせて15,900点を払う

3. Halu杯だけの決まり

チョンボは流局したら満貫払い

チョンボがあっても、その局は最後まで続けます。チョンボした人は、その局の終わりまでアガリ放棄です（14章）。山を壊すなどして続けられなくなったら、その場で流局にします。

局の終わり方扱い
誰かがアガったふつうのアガリと同じです。チョンボの罰（満貫払い）はありません
流局したチョンボした人が満貫払いをします（下の表）。聴牌・ノーテンの点棒のやり取りはしません

満貫払いは、満貫ツモと同じ払い方です。

チョンボした人払い方合計
子親に5,000点、子に3,000点8,000点
親子2人に6,000点ずつ12,000点
  • 流局した後の親は、ふつうの流局と同じです（4章の「連荘と本場」）。親がチョンボした時は、親が移ります。
  • 聴牌は宣言しますが、点棒のやり取りはしません。半荘が続くときは、本場を1本積みます。
  • リーチ棒はふつうと同じです。アガった人がもらい、流局なら供託として場に残ります。

場決めあり・起家はサイコロ

  • 予選も決勝も順位決定戦も、半荘ごとに牌を引いて席を決めます。
  • 使う牌は、3人卓が東・南・西と白、4人卓が東・南・西・北と白です。
  • 引いた牌の席に座ります。牌は1枚余ります。
  • 白を引いた人は、東の席に座ります。東を引いた人もいれば、その人は余った牌の席に座ります。
  • 白が余ったときは、全員が引いた牌の席に座ります。
例（3人卓）: Aが白、Bが東、Cが西を引き、南が余った → Aが東、Bが南、Cが西の席
  • 席が決まったら、東の席の人がサイコロを2個振って起家を決めます。
  • 3人卓では、出た目を自分から反時計回りに数えます。1・4・7・10は自分、2・5・8・11は下家、3・6・9・12は上家が起家です。
  • 4人卓では、1・5・9は自分、2・6・10は下家、3・7・11は対面、4・8・12は上家が起家です。
  • 組み合わせ表は、同じ卓で打つ人を示すだけです。表の並び順は、席ではありません。

時間制限

  • 予選・決勝1半荘目・順位決定戦は、40分です。
  • 決勝2半荘目は、時間制限なしです。最後まで打ちます。
  • 規定時間が来た局で終わります。その局は最後まで打ちます。
  • 終わった時の持ち点で順位を決めます。
  • 場に残ったリーチ棒は、終わった時のトップが取ります。

予選と決勝

  • 予選は、組み合わせ表のとおりに打ちます。抜け番の半荘は0ポイントです。
  • 予選の合計ポイントの上位が、決勝に進みます。
  • 予選の合計が同点なら、年齢が上の人が上位です。決勝に進む人も、これで決めます。
  • 同点の人の生年月日は、運営が聞いて幹部用ページに入れます。生年月日は、どのページにも出ません。
  • 決勝の順位は、決勝のポイントの合計で決めます。予選のポイントは足しません。
  • 決勝の合計が同点なら、予選の順位が上の人が上位です。
  • 決勝2半荘目は、決勝に出ない人も観戦します。

順位決定戦

  • 決勝に出ない人は、決勝1半荘目と同じ時間に、順位決定戦を1半荘打ちます。2半荘目はありません。
  • 卓は、予選の順位で上から分けます。人数が3で割り切れないときは、下の卓を4人にします。
  • 最終順位は、卓ごとに、その半荘の点棒が多い順です。卓をまたいで入れ替わりません。
  • 点棒が同じなら、予選の順位が上の人が上位です。
  • 途中で帰った人がいるときは、卓の分け方が変わります。点数ページの「決勝と順位決定戦の卓」で確かめてください。

4人卓（4人で3人麻雀を打つ）

  • 順位決定戦で4人になった卓は、4人で3人麻雀を打ちます。
  • 局ごとに、北家（親の上家）が抜けます。抜けた人は、その局は打ちません。
  • 親は、起家から順に下家へ移ります。東場・南場とも4局ずつです（東1〜東4局・南1〜南4局）。
  • 抜けた人の点棒は動きません。ツモもノーテン罰符も払いません。
  • 持ち点は、3人卓と同じです。
  • 南4局の親が、3人卓の南3局の親と同じ扱いです（アガリやめ）。
  • 抜けている人は、手牌をのぞいたり、口を出したりしないでください。

軽食

  • 軽食休憩はありません。
  • 軽食は各自で持ってきて、打ちながら食べてください。

点数の報告

  • 半荘が終わったら、卓の代表が 点数ページ に3人の点棒を入れます。
  • 点数ページでは、起家を「東」、その下家を「南」、残りの人を「西」にして入れます。
  • 4人卓は、起家から下家の順に「東」「南」「西」「北」にして、4人の点棒を入れます。
  • 順位決定戦は、順位だけを決めます（ポイントはつけません）。
  • マイナスの点棒も、そのまま入れてください。
  • チョンボの満貫払いは、流局した時に点棒で払います。払った後の点棒を入れます。
  • ポイントは自動で計算されます。計算のしかたは「12. 順位点とポイント」です。

4. 1局の流れ

親と局の進み方

  • 半荘は東場と南場の2周です。どちらも3局ずつです。
  • 親は起家から順に、下家（次の番の人）へ移ります。
  • 1局は、アガリか流局で終わります（Halu杯 チョンボがあっても局は続ける。3章）。
  • 洗牌（牌をかき混ぜること）はしません。局が終わったら、すぐ牌を卓の中へ流します。

流局と聴牌

  • 最後の牌までアガリがなければ流局です。途中で流局することはありません。
  • 聴牌の宣言は、東家・南家・西家の順です。手牌を開けて見せます。
  • 役がなくても、形が聴牌なら聴牌と認めます（形式聴牌）。
  • 聴牌していても「ノーテン」と言って伏せてかまいません。
  • 自分の手牌と鳴いた牌だけでアガリ牌を4枚使っている待ちは、聴牌と認めません。
  • ノーテン罰符は、2章の表のとおりです（場に3,000点）。

連荘と本場

  • 親がアガると連荘です。
  • 東場は、親が聴牌で流局すると連荘です。親がノーテンなら、親が移ります。
  • Halu杯 南場は、流局すると連荘です。親がノーテンでも、親は移りません。
  • Halu杯 南3局の親（ラス親）は、アガってトップなら、その局で半荘を終わりにできます（アガリやめ）。続けるかは親が決めます。
  • テンパイやめはできません。
  • 流局して親が移る時は、本場を1本積みます。
  • 本場1本につき、ロンは300点を足します。ツモは1人100点ずつ足します。
  • 子がアガると、本場は0本に戻ります。
  • 本場は卓の表示だけで数えます。百点棒は出しません。

海底と河底

  • 海底牌（最後にツモる牌）を引いた人は、カンとリーチができません。
  • 海底牌を引いてアガらなければ、1枚捨てます。これが河底牌です。
  • 河底牌は、ポン・カンできません。ロンはできます。

5. リーチ

  • 門前（鳴いていない）なら、リーチをかけられます。
  • 「リーチ」と言って、捨て牌を横に向け、千点棒を1本出します。
  • リーチの宣言牌でロンされなければ、リーチ成立です。
  • フリテンでもリーチできます。ツモ番が残っていなくてもリーチできます。
  • 宣言牌がポン・カンされたら、次の捨て牌を横に向けます。
  • リーチ後にアガリ牌を見逃してもかまいません。その後はフリテンになり、ツモでしかアガれません。
  • リーチ後の暗槓は、手の形（面子の組み合わせ）が変わらない時だけできます。

取り消しとリーチ棒

  • 「リーチ」と言っても、牌を捨てる前なら取り消せます。ただし、その局はアガリ放棄です。
  • 牌を捨てた後は取り消せません。
  • リーチ棒は、その後にアガった人が取ります。
  • 最後の局が流局で終わったら、場のリーチ棒はトップが取ります。
  • 聴牌していないリーチ（ノーテンリーチ）はチョンボです。

6. 鳴き（ポン・カン）

どれが優先か

同時に声がかかったら、ロン → ポン・カン の順に優先します。

  • 通らなかった鳴きは、罰則になりません。

ポン

  • 誰の捨て牌でもポンできます。
  • 取った牌を横に向けて置きます。向きで、取った相手が座っている方向を示します。
取った相手の席ポン大明槓
左左端を横に左端を横に
向かい真ん中を横に左から2番目を横に
右右端を横に右端を横に

食い替えは禁止

ポンした直後に、ポンした牌と同じ牌を捨てることです。するとアガリ放棄になります。

例: 手に5筒が3枚あり、5筒をポンして、残りの5筒を捨てる → 食い替え

カン

種類やり方
暗槓（アンカン）ツモの後、手の中の4枚を見せる。両端（または内側2枚）を伏せて右に出す
加槓（カカン）ツモの後、ポンした3枚に4枚目を重ねる
大明槓（ダイミンカン）人の捨て牌で、手の中の3枚と合わせて4枚にする
  • カンをしたら、王牌の最後から嶺上牌を1枚ツモります。
  • 槓ドラは、カンした時点ですぐにめくります（暗槓も明槓も同じ）。
  • 1局のカンは、全員合わせて4回までです。
  • 加槓の牌でロンされたら（搶槓）、そのカンはなかったことになり、槓ドラもめくりません。
  • 暗槓の牌では、どんな手でも搶槓できません（国士無双でも不可）。

鳴いた牌の置き場所

  • 鳴いた牌は自分の右側に置きます。複数あれば、手前から奥へ鳴いた順に並べます。暗槓も同じ場所です。

7. アガリとフリテン

アガリの形

  • 4面子＋1雀頭、七対子、国士無双の3つです。
  • 役が1つ以上ないとアガれません（一翻縛り）。
  • ツモなら「ツモ」、ロンなら「ロン」と言って手牌を開けます。
  • ツモの時は、まずアガリ牌を見せてから手牌を開けます。
  • 嶺上牌でのアガリは、すべてツモアガリです。
  • アガリの確認が終わるまで、手牌・捨て牌・山を崩さないでください。

ダブロンあり

Halu杯 1つの牌に2人がロンしたら、2人ともアガれます。払い方と、本場・リーチ棒の取り方は2章です。

フリテン

フリテンの時は、ツモでしかアガれません。

種類どんな時いつ解ける
捨て牌自分の捨て牌にアガリ牌がある待ちが変わるまで
同巡内アガリ牌が出たのにロンしなかった自分がツモって捨てた時
リーチ後リーチ後にアガリ牌を見逃したその局の終わりまで解けない

役の重なり

  • 一緒に成り立つ役は、すべて重ねて数えます。
  • 嶺上開花と海底摸月は重なりません。

8. ドラ

種類決め方
表ドラドラ表示牌の次の牌。萬子は 1萬→9萬→1萬。字牌は 東→南→西→北→東、白→発→中→白 の順
槓ドラカンのたびに、表示牌を1枚ずつ増やす
裏ドラリーチした人のアガリだけ。表示牌の下の牌で見る。槓ドラの下も見る
赤ドラ赤い5筒・5索が1枚ずつ
  • ドラは1枚につき1翻です。
  • ドラは役ではありません。ドラだけではアガれません。

11. 点数表

点数は、点数表のページにまとめました。ツモで北家の分の半分がいくら足されるかも、そこに書いてあります。

  • Halu杯 ツモ損なしです。いない北家の分を、親と子で半分ずつ払います（2章）。
  • 切り上げ満貫あり。30符4翻と60符3翻は満貫です（子8,000点、親12,000点）。
  • 役満の役以外は、どれだけ翻を重ねても三倍満までです（数え役満なし）。
  • ダブル役満は2倍、トリプル役満は3倍です。
  • 本場は、ロンなら1本につき300点を足します。ツモは1人100点ずつ足します。

点数の払い方と申告

  • ロンは放銃した人が1人で全部払います（ダブロンなら2人分）。ツモは2人がそれぞれ払います。
  • 点数はアガった人が言います。点数は、いちばん高くなる数え方で数えます。
  • ツモの時は、子の払い → 親の払いの順に言います。本場があれば足した点も言います。
  • 点棒のやり取りは、次の局が始まる前に済ませます。
  • 渡し間違いは、その半荘の中なら直します。半荘が終わった後は直しません。
例（1本場の子のツモ）: 「1,500・2,500 は 1,600・2,600」

12. 順位点とポイント

  • 半荘が終わった時の持ち点で順位を決めます。
  • 持ち点・返し・順位点は、回ごとに決めます。点数ページの「ポイントの計算」に、その回の数字が出ます。
  • 1,000点が1ポイントです。100点は0.1ポイントで、丸めません。

点数ページに3人の点棒を入れると、自動で計算されます。

同点のとき

  • 半荘の最後が同点なら、順位点を分けます。
  • 割り切れない分は、起家に近い人が多く取ります。
  • 流局で終わった時に場のリーチ棒があれば、トップが取ります。トップが同点なら、同点の人で分けます。
  • 予選の合計・決勝・順位決定戦の同点は3章です。

14. 反則と罰則

アガリ放棄

その局の終わりまでアガれず、ポン・カン・リーチもできなくなります。牌はツモって捨て続けます。

反則どんな時
多牌・少牌手牌が多い・少ない（カンの分を除いて14枚以上・12枚以下）
先ヅモ上家が捨てる前にツモった
食い替え6章
空鳴き「ポン」「カン」と言って鳴かなかった
リーチの取り消し「リーチ」と言って、捨てる前にやめた
手を見せないアガリ宣言「ツモ」「ロン」と言っただけで手牌を開けない
鳴きの言い間違い「ポン」「カン」を言い間違えた
誤った鳴き面子にならないのにポン・カンした（鳴きはなかったことにする）

「ツモ」と「ロン」の言い間違いは、注意のうえ言い直してかまいません。

アガリ放棄なのにポン・カン・リーチをしたら、チョンボです。

チョンボ（Halu杯 満貫払い）

  • アガれない手でアガリを宣言し、手牌を開けた。
  • ノーテンリーチ。リーチ後に手の形が変わる暗槓をした。
  • 山や手牌をわざと崩して見せた。
  • 山を壊すなどして、続けられなくした。
  • チョンボがあっても、局は最後まで続けます。チョンボした人は、その局の終わりまでアガリ放棄です。
  • 山を壊すなどして局を続けられなくなったら、その場で流局にします。
  • 誰かがアガったら、チョンボの罰はありません。
  • 流局したら、チョンボした人が満貫分の点棒を払います（3章の表）。ノーテン罰符はありません。
  • 流局した後の親と本場は、3章のとおりです。

くり返すと罰則になる行為

次の行為は、くり返さないでください。

  • 声を出さずに鳴いた。動作が先で、声が明らかに遅れた。
  • わざとでなくても、牌を2枚以上見せた（山・手牌とも）。
  • 関係ない場面での強打・長考をくり返した。
  • ツモに時間をかける動作（牌を絞る・振りかぶる）をくり返した。
  • ツモった牌を手牌に入れる動作（小手返しなど）をくり返した。
  • ツモが早く、ポン・カンの時にツモ牌を見てしまうことをくり返した。
  • ため息やぼやきなど、相手を惑わす言動をくり返した。

15. 打ち方の決まり

  • ポン・カン・リーチ・ロン・ツモは、必ず声に出してから動きます。
  • ツモは、上家が牌を捨て終わってから取ります。山に触ったら、もう鳴けません。
  • ツモって捨てるまでは片手で行います。牌を握ったままツモらないでください。
  • ツモった牌を、手牌の中に混ぜてはいけません。
  • 捨て牌は左から右へ、6枚ずつ並べます。7枚目から下の段へ。
  • 一度河についた牌は、取り戻せません。
  • 捨て牌にむやみに触らないでください。
  • ツモや打牌は、速すぎず遅すぎないペースで行います。
  • 強打は禁止ではありませんが、くり返すと罰則の対象になります。

一般的な3人麻雀のやり方と、一般的な競技ルールを合わせて、わかりやすく書いたものです。細かい解釈で迷ったときは、運営が判断します。3麻 の印は3人麻雀だけの決まり、Halu杯 の印は本大会だけの決まりです。
