## 1. ねらい

- Halu杯は1日で決まる短期戦。リーグは試合数を多くして、いま誰が一番強いかを決める。
- 全員が全員と同じ回数だけ対戦する。1人の試合数も一定以上にする。
- シーズンは番号で呼ぶ（「Haluリーグ〜シーズン1〜」から。年は付けない。2026-11-08 主催）。
- 年2回か、2年で3回のペースで続ける。
- 1人あたり、月に12半荘×4か月ほど。参加者の案で変えてよい。

## 4. 対戦カード（`league/tools/cards.py`）

シーズン全部（60回戦・120卓）の対戦カードを、始まる前に作って公開する。
始まった後は書き直さない（season.json の from の日から、道具が書くのを拒む）。

### できる形（検算の結果。2026-11-08・seed 1）

| 項目 | 結果 |
|---|---|
| 1人の試合数・休み | 全員 48半荘・12回 |
| 同じ卓になる回数 | 45組すべて16回 |
| 同じ顔ぶれの卓 | なし（120卓すべて別） |
| 15回戦ごと | 各人12半荘。どの2人も4回ずつ |
| 5回戦ごと | 全員が1回ずつ休む |
| 休みが続く | 0回 |
| 同じ2人がそろって休む | 最大3回（3回が10組・2回が15組） |

- 15回戦は、ほぼ1か月。月ごとに対戦の回数がそろうので、途中で止めても偏りが小さい。
- そろって休む回数は、試合数と対戦の回数には響かない。

### 作り方

- 10名を a0〜a4 と b0〜b4 の2組に分ける。番号は5で割った余りでずらす。
- 元の3回戦（休みは a0 と b_t）を5回ずつずらすと、15回戦になる。
- 元の3回戦は、どの2人も合わせて4回ずつ同じ卓になるものを選ぶ（80通り）。
- 4つの区切りには、ずらしてできる顔ぶれが互いに重ならない組を選ぶ（5,305通り）。
- 誰を a0〜b4 にするかは、くじ（--seed）で決める。同じ seed なら同じ表になる。
- 休みが2回続かないように、回戦の並びを入れ替える。

### 使い方（リポの根で）

```
python league/tools/cards.py --season season1            … 作って検算を出すだけ（書かない）
python league/tools/cards.py --season season1 --write    … cards.json に書く
python league/tools/cards.py --season season1 --check    … いまの cards.json を検算する
```

- いま組めるのは、10名・四麻・1回戦2卓で、回戦が15の倍数の形だけ。
- 人数や卓の数が変わったら、作り方を足す。

## 7. 点数入力（`league/score/index.html`）

Halu杯の点数入力（`kai/score/`）を元にした。席は卓で決めるので、Halu杯の場決めの会と同じく、名前ごとに点棒を入れる。

| 欄 | 中身 |
|---|---|
| 自分の名前 | スコアボードと同じ。選ぶと、自分のカードが先に出る |
| 対戦カード | 自分のまだ入っていないカード → ほかのまだのカード → 入力済み（入れた新しい順）。最初は自分のまだの一番前 |
| 打った日 | 最初は今日（日本時間）。入力済みの卓は、送った日 |
| 点棒 | カードの4人の名前ごと。百点単位（25,300点 → 253）。3人入れると、残りの1人は自動 |
| 最近の入力 | 入れた新しい順に5卓。「この卓を直す」で上の欄に出す |

- マイナスは「−」ボタンで付ける（スマホの数字キーにはマイナスがない）。
- 送る前に確かめる: 合計が100,000でない・100,000点以上の点棒・期間の外の日・上書き。どれも、はいで送れる。
- 送れないもの: 4人そろっていない・百点単位でない・今日より後の日・同じ回戦のほかの卓に入っている人。
- 入力済みの卓は、緑の帯で「入力済み」と出す。入れ直して送ると上書き、「取り消す」で消す。
- 自動の読み直しは、入力中の欄を作り直さない（Halu杯と同じ）。

## 8. 調整表（`league/chousei/index.html`）

シーズンの期間の日に、各人が○△×を付ける。まだ打っていない卓のうち、4人とも○のカードを日ごとに出す。

| 欄 | 中身 |
|---|---|
| 自分の名前 | ほかの2ページと同じ。見通しでは、自分のカードと名前が太字になる |
| 自分の予定 | 今日（始まる前は初日）から最終日まで、1日1行。○＝打てる、△＝まだわからない、×＝打てない |
| 送信の帯 | 送っていない印の数と「送信する」。印を付けると、画面の下に残る |
| 日ごとの見通し | 日ごとの○△×と未回答の人。4人とも○のカードを、回戦の順に6卓まで |

- 出す日は season.json の slots で決める。いまは土曜のランチ後（基本）と、月〜金の夜。
- 平日の夜の行は「平日の夜も出す」で出す。出すかどうかは、端末に覚える。
- 同じ印をもう一度押すと消える。送るまでは、行に色が付く。
- 送っていない印があるまま名前を変えたり、ページを閉じたりすると、確かめる。
- 見通しには、基本の日は毎回出す。ほかの日は、4人とも○のカードがある日だけ出す。
- 見通しは最初は6日分。「すべて見る」で全部出る。
- 6卓に入らない自分のカードは、3卓まで足して出す。△の人も入れて打てる卓は、数だけ出す。
- 印のボタンは図形で描く（○と×の字は、端末の字の形しだいで小さく出るため）。
- 打つ日を決める（確定）欄はない。決めるのは LINE で行う。
- 日ごとの見通しには、読み込んだ時刻を出す。予定の印では、受け口の最終更新が動かないため。

## 10. 受け口のデータの形（`league/gas/Code.gs`）

`<受け口>?season=<シーズン>` の返り:

```json
{ "ok": true, "data": {
  "season": "season1",
  "rounds": { "<回戦>": { "<卓>": {
    "p": ["P1", "P5", "P8", "P9"], "raw": [32100, 28400, 22000, 17500],
    "d": "2027-01-09", "ts": "2027-01-09 15:10:00" } } },
  "roster": { "P1": "<名前>" },
  "avail": { "P1": { "2027-01-09": "o", "2027-01-12": "x" } },
  "updated": "2027-01-09 15:10:00" } }
```

- avail は予定の印。o＝○、t＝△、x＝×。付けていない日は入れない。
- updated は、点数か名簿を受けた時刻。予定の印では動かさない（Halu杯の打ち上げの出欠と同じ）。

送り方（本文は JSON。Content-Type は付けない＝Halu杯と同じ）:

```
POST {action:'score', season, round:'18', table:2, p:[4人], raw:[4人の点棒], d:'YYYY-MM-DD'} … 1卓ぶん。同じ卓は上書き
POST {action:'clear', season, round, table}                                      … 1卓ぶんを消す
POST {action:'avail', season, p:'P3', marks:{'YYYY-MM-DD':'o'|'t'|'x'|''}}         … 1人ぶんの予定。日ごとに上書きし、'' は消す
POST {action:'roster', season, names:{P1:'名前', …}}                              … 名簿。渡した番号だけ直し、'' で消す
```

- p と raw は対戦カードの並び（席の順ではない）。同点の割り切れない分に使う。
- d は打った日。ts は受け口が入れた時刻（日本時間）。
- 返事は `{ok:true, data:<GET と同じ>}` か `{ok:false, error:'…'}`。
- 同じ回戦のほかの卓に入っている人を送ると、`error:'dup'`（players に該当者）で断る。
- 置き場は Script Properties の `S_<シーズン>_<回戦>`。1つ9KBまで、全体で500KBまで。
- 1シーズンは30KBほど（点数120卓で15KB、予定の印で15KB）。
- 予定の置き場は `A_<シーズン>_<P番号>`。1人400日まで持てる（7KBほど）。
- 名簿は `R_<シーズン>`、最終更新は `U_<シーズン>`、送信履歴は `LOG`（直近100件）。

断るときの error:

| error | わけ |
|---|---|
| bad_json | 本文が JSON の形でない（並びや null も） |
| season | シーズンの名前の形が違う |
| action | 知らない操作 |
| round | 回戦が 1〜99 でない |
| table | 卓が 1〜10 の整数でない |
| player | P番号の形が違う。点数では、3人か4人でない・同じ人が2回。名簿では、番号が1つもない |
| score | 点棒の数が人数と違う・百点単位でない・範囲の外（−200,000〜999,900） |
| date | 日付の形が違う・ない日付。点数では、今日より後の日も |
| dup | 同じ回戦のほかの卓に入っている人がいる（players に該当者） |
| mark | 印の値が違う・marks が空か並び・1回に200日を超える・1人400日を超える |
| names | 名簿が {P番号: 名前} の形でない |
| name | 名前が21字以上・< > か制御文字を含む |
| busy | ほかの送信と重なり、30秒待っても書けない |
