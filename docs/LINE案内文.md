# LINE に貼る案内文

会ごとに、下の文をそのまま LINE のグループに貼る（固定のアナウンスに置くと、毎回そこから開ける）。
URL の `openExternalBrowser=1` は、LINE の中のブラウザでなく Safari や Chrome で開くための印（消さない）。

## Halu杯

```
【Halu杯】組み合わせと点数のページです。毎回このページを使います。
https://syowstar-cyber.github.io/mahjong/kai/?openExternalBrowser=1

ホーム画面に入れると、アプリのように開けます（入れなくても使えます）。
・iPhone: 開いたページで共有ボタン（四角に上向きの矢印。見当たらなければ「…」の中）→「ホーム画面に追加」
・Android: 右上の「︙」→「ホーム画面に追加」または「アプリをインストール」
はじめに「自分の名前」を選ぶと、自分の卓と席が出ます。
```
