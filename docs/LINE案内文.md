# LINE に貼る案内文

会ごとに、下の文をそのまま LINE に貼る。貼る先は各文の見出しのとおり（固定のアナウンスに置くと、毎回そこから開ける）。
URL の `openExternalBrowser=1` は、LINE の中のブラウザでなく Safari や Chrome で開くための印（消さない）。
参加者用・幹部用・運営用のどれにも付ける（2026-11-19 主催「付けるにそろえる」）。LINE の中のブラウザの不具合で、ボタンが効かなくなるのを避けるため。名前やチェックも、1つのブラウザに保存される。
ほかの会の文を足すときは、URL の末尾を `?g=<会>&openExternalBrowser=1` にする（`halu` は `?g=` なし）。

## Halu杯

### 参加者用（参加者のグループに貼る）

```
【Halu杯】参加者ページです（組み合わせと点数）。毎回このページを使います。
https://syowstar-cyber.github.io/mahjong/kai/?openExternalBrowser=1

ホーム画面に入れると、アプリのように開けます（入れなくても使えます）。
・iPhone: 開いたページで共有ボタン（四角に上向きの矢印。見当たらなければ「…」の中）→「ホーム画面に追加」
・Android: 右上の「︙」→「ホーム画面に追加」または「アプリをインストール」
はじめに「自分の名前」を選ぶと、自分の卓と席が出ます。
```

### 幹部用（幹部にだけ送る。参加者のグループには貼らない）

```
【Halu杯】幹部用ページです（準備と出席確認など）。毎回このページを使います。
https://syowstar-cyber.github.io/mahjong/kai/kanbu/?openExternalBrowser=1
```

### 運営用（運営の1人にだけ送る。当日の操作か決勝最終実況がある回だけ）

```
【Halu杯】運営用ページです（当日の操作と、決勝最終実況の入力）。
https://syowstar-cyber.github.io/mahjong/kai/unei/?openExternalBrowser=1

運営の1人だけが使います。ほかの人には送らないでください。
```
